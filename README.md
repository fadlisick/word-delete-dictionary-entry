The Word You'd Delete From the Dictionary entry: one word, nothing else.
The word is `hippopotomonstrosesquippedaliophobia` (36 letters), the fear
of long words. Deleting it erases the phobia's own name, and that name
is itself one of the longest words in the dictionary, so the whole joke
lives inside the word.

`main.py` writes exactly that word to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set) and checks the read-back.

## Run it

```sh
python3 main.py
```
